# Changelog

## 1.0.0

First release.

- Web interface (Material 3, light/dark, phone and desktop, English and Bahasa Indonesia).
- Optimizers for images, Sparrow atlases, ASTC textures, video, audio, fonts, scripts, shaders and JSON.
- Backup before every run; verification of atlases, scripts and JSON before a file is replaced.
- Live per-file progress (bar, percentage, current step) with customizable display.
- Font trimming by chosen letters, symbols and alphabets.
- Skip rules by file-name words, folders and patterns.
- Guided setup for Pillow, fontTools, FFmpeg, astcenc and (optionally) oxipng.
